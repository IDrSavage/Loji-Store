# LOJI | لوجي

متجر منتجات سودانية شعبية. صفحة واحدة بدون سيرفر، والطلبات توصل على واتساب.

## تعديل المنتجات والأسعار

كل شيء في ملف `products.js`:

- `STORE.whatsapp`: الرقم اللي تستقبل عليه الطلبات
- `STORE.groupLink`: رابط مجموعة الواتساب (اختياري)
- `PRODUCTS`: المنتجات، والسعر في `price`

الصور في مجلد `img/`.
